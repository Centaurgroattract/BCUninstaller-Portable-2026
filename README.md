# BCUninstaller Windows Setup Notes

## Download & Install

> Setup notes for **BCUninstaller** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Complete activation in the installer if required
5. Restart if the installer asks — then launch **BCUninstaller** from the Start menu

## What you can use it for

- Core BCUninstaller features on Windows desktop
- Install and configure BCUninstaller for daily use
- Import, edit, and export with BCUninstaller tools
- Tune settings and profiles inside BCUninstaller
- Integrate BCUninstaller into your existing workflow
